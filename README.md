# 🏮 冰箱管家 - 家庭冰箱库存 · 智能菜谱推荐

一个为夫妻二人日常管理食材、做饭和减脂饮食规划打造的 **Web App**。纯前端，零后端，打开即用。

## ✨ 功能特色

### 🧊 冰箱库存管理
- **添加/编辑/删除** 食材，支持分类、数量、单位、保质期
- **搜索** 和 **分类筛选**（蔬菜、肉类、海鲜、水果等 9 大类）
- **卡片/列表** 两种视图模式
- **智能过期提醒**：快过期自动高亮，过期自动红色提示
- **排序**：按名称、分类、保质期、添加时间
- **图片上传**：支持本地图片上传保存为 Base64
- **一键清空** 所有库存

### 🍳 智能菜谱推荐
- 根据冰箱现有食材 **自动匹配** 最合适的菜谱
- **匹配率显示**，缺少食材一目了然
- 支持 **川菜 / 减脂餐 / 快手菜** 分类筛选
- 内置 **130+ 道真实中文菜谱**
  - 55 道川菜（麻婆豆腐、宫保鸡丁、回锅肉…）
  - 50 道减脂餐（鸡胸肉沙拉、三文鱼轻食、虾仁藜麦…）
  - 30 道家常快手菜（番茄炒蛋、青椒肉丝、可乐鸡翅…）

### 📊 数据统计
- **库存总数**、分类数量、临期数量一目了然
- **分类占比饼图**
- **保质期状态饼图**（正常/快过期/已过期）
- **分类柱状图**
- 使用 **Chart.js** 渲染图表

### 📂 Excel/CSV 导入导出
- **导出 Excel**：将库存导出为 `.xlsx` 文件
- **导出 CSV**：导出为 `.csv` 文件（带 UTF-8 BOM）
- **导入 Excel/CSV**：自动识别字段映射
- **模板下载**：提供导入模板

### 🎨 视觉设计
- **中国风 + 现代极简** 风格
- **毛玻璃卡片** 设计，柔和阴影
- **米白 + 淡金 + 中国红点缀**
- **Noto Serif SC** 字体，高级感十足
- **响应式布局**，手机和电脑都完美适配

### ⌨️ 用户体验

- **Toast 提示** 系统

## 🚀 快速开始

### 方式一：直接打开（推荐）

1. 下载本项目到本地
2. 双击打开 `index.html`
3. 开始使用！

### 方式二：使用本地服务器

```bash
# Python 方式
python -m http.server 8080
# 然后访问 http://localhost:8080

# 或者 Node 方式
npx serve .
```

### 方式三：部署到服务器

将整个项目目录上传到任意 Web 服务器（如 Nginx、Apache、Vercel、Netlify 等），配置为静态站点即可。

> **注意**：所有数据存储在浏览器的 **LocalStorage** 中。清除浏览器缓存会导致数据丢失，建议定期 **导出 Excel** 备份。

## 📖 使用指南

### 添加食材
1. 点击导航栏「库存」
2. 点击「＋ 添加食材」
3. 填写食材名称、分类、数量、保质期等信息
4. 点击「添加」完成

### 导入 Excel
1. 进入「设置」页面
2. 在「数据导入导出」区域
3. 点击「选择文件导入」
4. 选择 `.xlsx`、`.xls` 或 `.csv` 文件
5. 系统自动识别字段并导入

### 推荐菜谱
1. 首页或点击「菜谱」页面
2. 系统根据冰箱库存自动推荐
3. 匹配率高的菜谱排在前面
4. 点击菜谱卡片查看详情和烹饪步骤

### 新增菜谱（自定义）
目前菜谱数据为内置，可以通过修改 `js/data.js` 文件中的 `RecipeDB` 数组来添加自定义菜谱。

格式示例：
```javascript
{
  id: "custom1",
  name: "自定义菜名",
  cuisine: "中式",
  difficulty: "简单",
  cookTime: 15,
  calories: 300,
  tags: ["家常","自定义"],
  isSichuan: false,
  isDiet: false,
  isQuick: true,
  ingredients: ["食材1","食材2","食材3"],
  steps: ["步骤1","步骤2","步骤3"]
}
```

## ❓ 常见问题

**Q: 数据会丢失吗？**
A: 数据存储在浏览器 LocalStorage。清除浏览器缓存、更换浏览器或设备会导致数据丢失。**建议定期导出 Excel 备份。**

**Q: 如何在不同设备间同步数据？**
A: 在设备 A 导出 Excel，在设备 B 导入即可。

**Q: 为什么图表不显示？**
A: 需要网络连接加载 Chart.js 库。首次加载后浏览器会缓存。

**Q: 如何修改菜谱数据？**
A: 编辑 `js/data.js` 文件的 `RecipeDB` 数组。修改后刷新页面即可。

**Q: 如何新增食材分类？**
A: 在 `js/inventory.js` 的分类选项中添加即可。

**Q: 支持多人同时使用吗？**
A: 当前为单机版，数据存储在本地浏览器。如需多人共享，可以部署到服务器后使用。
